# Routing

[go_router](https://pub.dev/packages/go_router) with type-safe routes
generated by [go_router_builder](https://pub.dev/packages/go_router_builder).

| File | Role |
|---|---|
| `app/router/app_routes.dart` | Route classes + annotations (`part 'app_routes.g.dart'`) |
| `app/router/route_paths.dart` | Path constants (`RoutePaths.posts`, `.home`, …) |
| `app/router/app_router.dart` | The `GoRouter` (initial location, guard, 404) |
| `app/router/guards/auth_guard.dart` | Redirect logic |
| `app/shell/app_shell_scaffold.dart` | Bottom navigation around the branches |

## Route tree

```
StatefulShellRoute (AppShellRoute → AppShellScaffold)
├── branch PostsBranch
│   └── /posts                 PostsRoute
│       └── /posts/:id         PostDetailRoute(id)
└── branch SettingsBranch
    └── /settings              SettingsRoute
        └── /settings/account  AccountRoute      (protected)
/sign-in?from=…                SignInRoute       (outside the shell)
*                              NotFoundPage      (errorBuilder)
```

Each shell branch keeps its own navigation stack; tapping the active tab
pops back to its root.

## Navigating

Always use the typed routes:

```dart
const PostsRoute().go(context);
PostDetailRoute(id: post.id).go(context);   // path params are typed
const SignInRoute(from: '/settings/account').push(context);
```

Pages don't import the router. The route passes callbacks instead:

```dart
class PostsRoute extends GoRouteData with $PostsRoute {
  @override
  Widget build(BuildContext context, GoRouterState state) => BlocProvider(
    create: (_) => getIt<PostsBloc>()..add(const PostsRequested()),
    child: PostsPage(onPostTap: (id) => PostDetailRoute(id: id).go(context)),
  );
}
```

## Adding a route

1. Add the path to `RoutePaths`.
2. Add a `GoRouteData` class with `with $<Name>Route` and register it with
   `@TypedGoRoute` (top level) or inside an existing `TypedGoRoute(routes: …)`
   / shell branch.
3. For a new tab: add a `TypedStatefulShellBranch` **and** a
   `NavigationDestination` in `AppShellScaffold` (same order).
4. `dart run build_runner build`.

The `feature` and `page` bricks print a ready-to-paste snippet.

## Guards

`AuthGuard.redirect` runs on every navigation and whenever `AppSession`
notifies (`refreshListenable`):

- signed out + path in `protectedPaths` → `/sign-in?from=<requested>`;
- signed in + on `/sign-in` → back to `from` (or `RoutePaths.home`).

Protect a page by adding its path prefix to `protectedPaths` in
`AppRouter`. `AppSession` is a minimal demo: replace `signIn` with your
auth feature, keep `AppSession` as the single source of truth the router
listens to.

## Errors (404)

Unknown locations render `NotFoundPage` with a "Go home" button
(`errorBuilder`).

## Deep links

Configured for a custom scheme on both platforms (`cleanstarter://`):

- Android: `intent-filter` + `flutter_deeplinking_enabled` in
  `AndroidManifest.xml`.
- iOS: `CFBundleURLTypes` + `FlutterDeepLinkingEnabled` in `Info.plist`.

Try it:

```sh
adb shell am start -a android.intent.action.VIEW -d "cleanstarter://app/posts/1"
xcrun simctl openurl booted "cleanstarter://app/posts/1"
```

The URI host (`app`) is ignored; the path (`/posts/1`) is routed. For
**https App Links / Universal Links**, add an `autoVerify` intent filter
with your domain (Android) and the Associated Domains entitlement (iOS),
and host `assetlinks.json` / `apple-app-site-association` on that domain.
Rename the scheme for your app (it is not changed by `tool/rename.dart`).
